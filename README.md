# NAPRAWA PC – PARAGON PRO AI — kanał wydań

To publiczne repozytorium służy wyłącznie do publikowania instalatorów Windows i metadanych automatycznych aktualizacji przez GitHub Releases.

Wydanie jest gotowe dla aktualizatora dopiero wtedy, gdy zawiera instalator NSIS `Setup_*.exe` oraz `latest.yml`; pliki `.blockmap` umożliwiają aktualizacje różnicowe.

Publikacja jest wykonywana przez GitHub Actions z prywatnego repozytorium źródeł. Token publikujący nie jest przechowywany w aplikacji.

Na razie nie opublikowano jeszcze pierwszego wydania. Po uruchomieniu konfiguratora z pełnego pakietu FIX26 workflow zbuduje i opublikuje pierwszą wersję.
